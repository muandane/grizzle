# Decision: Unified Pre-v0.3.0 Preparation Pull Request

- **Date**: 2026-11-19
- **Author**: Chief of Staff / Zine Moualhi
- **Scope**: Issues #64, #66, #65
- **Status**: Approved

## Context
Following the merge of the 9-PR production readiness stack (#73 through #82), three open enhancement issues remained before cutting `v0.3.0`:
1. Issue #64: Declarative SQL linter rule expansion (L016, L032, L033, L049, L051).
2. Issue #66: Pre-flight migration simulation sandbox for lock hold duration and constraint validation.
3. Issue #65: Interactive pull request sticky comment with migration diff and hazard analysis.

Rather than authoring another multi-branch dependent stack, the operator requested delivering all three enhancements in a single, non-stacked pull request targeting `main`.

## Decision
On 2026-11-19, the team decided to bundle Issues #64, #66, and #65 into branch `feat/batch-lint-simulate-action`.

### Key Choices
1. **Rule ID Canon**: Rule ID `L003` remains `NamingConvention` (snake_case check). The Monetary Type Guard is assigned `L032` per `docs/LINTER_SPEC.md` to avoid breaking existing rules. Table comment requirement is assigned `L016`, multi-tenant cascade guard is `L033`, excessive index width is `L049`, and low-cardinality leading prefix is `L051`.
2. **Simulation Rollback Guarantee**: Pre-flight simulation runs inside an explicit transaction (or savepoint for SQLite) with mandatory rollback before return. It profiles individual step timing and flags steps exceeding `--max-lock-duration`.
3. **Sticky In-Place Comments**: `action.yml` updates existing plan comments using the anchor `<!-- grizzle-action-comment -->` rather than spamming pull request discussions.
